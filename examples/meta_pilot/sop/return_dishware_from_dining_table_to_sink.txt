Name: Return dishware from dining table to sink

Description:
Objects:
Dishes (plates, bowls, cutlery).

From: Dining table.
To: Kitchen sink.

Starting State:

Items: Dishware (plates, bowls, cutlery/utensils).
Position: Randomly placed on the dining table in varied positions and orientations.
Reset: Randomize placement, number, and type of dishware after each episode.

Constraints / Avoid: Do not rush — place items carefully into the sink.

Steps:
1. Walk to the table and stand still for 1 second.
2. Start with arms in a neutral position. Pick up 1 plate or bowl at a time (gather 2–3 utensils together).
3. Walk to the sink and stop for 1 second.
4. Lower the item flat into the sink basin. Return arms to a neutral position.
5. Repeat for each dish; group 2–3 utensils in one hand between trips.

Diversity: Vary the number of items. Switch between plates, bowls, and silverware. Alternate using your left or right hand to pick items up. Change item positions and table settings. Mix plate sizes (dinner, salad, bowl). Swap dish set every session.
